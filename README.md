# Cookie Protocol Website

Static GitHub Pages site for Cookie Protocol.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

The site is intentionally no-build: GitHub Pages can serve `index.html`, `styles.css`, and `assets/images/*` directly.
